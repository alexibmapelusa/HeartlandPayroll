Heartland Payroll System
Este proyecto implementa un sistema de nómina para la empresa Heartland Cars of America.

Características:
* Clases de Empleados: FullTimeEmp, PartTimeEmp y SalesEmp. * Cálculos Automáticos: Incluye lógica para horas extra (150%) y comisiones de ventas. * Formato Profesional: Generación de recibos de pago con formato de dos decimales usando DecimalFormat
